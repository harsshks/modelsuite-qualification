# [UI/UX] Implement a Premium Dark Mode System with Micro-Animations

## Description
We want to add a comprehensive, beautiful dark theme across the entire application, focusing on high-end aesthetics rather than just simply inverting colors.

## Proposed Idea & Direction
* **Design Details:** Use deep, rich grays or dark blues (e.g., `#0f172a`) for backgrounds, and utilize subtle glowing borders or soft drop-shadows to separate layers and elevate components.
* **The Toggle:** Create a custom, beautifully animated theme toggle switch (e.g., a sun that smoothly morphs into a moon) in the main navigation bar.
* **Goal:** Provide a modern, night-owl friendly experience that looks state-of-the-art and highly professional.
