# [UI/UX] Redesign the Available Tasks Discovery Experience (`AvailableTasksList.jsx`)

## Description
We want to upgrade the task browsing experience to feel less like a standard database list and more like a modern, premium marketplace (similar to Airbnb or Dribbble). 

## Proposed Idea & Direction
* **Grid/Masonry Layout:** Replace the standard vertical list with a responsive grid of rich, interactive "Task Cards".
* **Card Details:** Cards should feature a prominent bounty/reward tag, stylized typography for the task title, category pills, and a subtle gradient background or border that glows on hover.
* **Filtering:** Add a sleek, horizontal scrolling filter bar at the top with customized icons for different task categories.
* **Goal:** Make finding and accepting tasks visually exciting and highly engaging for talent.
